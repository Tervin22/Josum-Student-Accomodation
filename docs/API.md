# API Documentation

Swagger/OpenAPI is generated by the NestJS API at `/docs`.

Key endpoint groups:

- `/auth`: student registration, login, refresh tokens, logout, password reset, first admin bootstrap, current user
- `/phases`: phase availability and administrator room-count management
- `/applications`: student applications, status history, administrator status updates
- `/documents`: validated uploads and authenticated downloads
- `/users`: administrator student/user management
- `/settings`: system settings and email template CRUD
- `/notifications`: user notifications
- `/audit-logs`: administrator audit log search

All protected endpoints use Bearer JWT access tokens. Administrator endpoints additionally require the `ADMINISTRATOR` role.
